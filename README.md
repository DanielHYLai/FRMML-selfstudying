# Financial Risk Management with Machine Learning — Self-Study Notes

This repository contains personal study notes and Jupyter notebooks documenting my journey through machine learning applied to financial risk management. It is a self-directed learning project, not a formal course, textbook, or production codebase.

## About

Financial risk management sits at the intersection of statistics, economics, and increasingly, machine learning. This repository is where I work through the underlying theory, derive and verify the mathematics behind it, and implement the concepts in Python to build intuition.

The notes reflect my own understanding as I learn, and are refined over time as I catch and correct mistakes. They are shared publicly in case they are useful to others on a similar learning path, but they should not be treated as an authoritative or peer-reviewed reference.

## Reference

The structure and conceptual grounding of these notes draw on:

> Abdullah Karasan, *Machine Learning for Financial Risk Management with Python: Algorithms for Modeling Risk*, O'Reilly Media, 2022. ISBN: 9781492085256.

## Disclaimer

These notes are for educational purposes only and do not constitute financial, investment, or risk management advice. Code and models here are simplified for learning purposes and have not been validated for real-world trading, risk modeling, or decision-making use.
